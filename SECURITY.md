# Security Policy

## Supported versions

Only the latest `main` (and the deployment running from it at
`https://ward.rukavina.app`) gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository
([private vulnerability reporting](https://github.com/rukavina-git/Ward/security/advisories/new)).

Include what you found, how to reproduce it, and what an attacker could
do with it. Prompt-injection findings are in scope: tell us the input and
what the assistant did. You'll get a reply within 7 days.

Please don't run load or denial-of-service tests against
ward.rukavina.app.
