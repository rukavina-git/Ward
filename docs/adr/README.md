# Architecture decision records

One file per decision: `NNNN-short-title.md`, numbered in order. Never
edit an accepted ADR's decision; write a new one that supersedes it.

Template:

```
# N. Title

Date: YYYY-MM-DD
Status: Proposed | Accepted | Superseded by NNNN

## Context
What problem, what constraints. Plain words.

## Options
Each option considered, with its main pro and con.

## Decision
What we chose.

## Consequences
What gets easier, what gets harder, what we'd revisit and when.
```
